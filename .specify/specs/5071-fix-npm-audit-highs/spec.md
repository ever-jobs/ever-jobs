## 1. Problem Statement

`npm audit` reports high-severity advisories in transitive dependencies:

- `js-yaml@4.2.0` and `js-yaml@3.14.2` — quadratic DoS in merge-key handling
- `fast-uri@3.1.2` — host confusion via encoded backslash / failed IDN canonicalization

These are pulled in by several dev and runtime packages but can be patched within their current semver ranges using `package.json` `overrides`.

## 2. Goals

- Bump all `js-yaml` 4.x consumers to `^4.3.0`.
- Bump all `js-yaml` 3.x consumers to `^3.15.0`.
- Bump all `fast-uri` consumers to `^3.1.4`.
- Leave `package.json` direct dependency ranges unchanged.

## 3. Non-Goals

- Do not attempt to patch `brace-expansion` in this spec. Its high-severity advisory (`<=5.0.7`) affects the `1.x` and `2.x` copies used by `minimatch@3/5/9.0.9`; fixing it requires forcing major transitive upgrades across `eslint`, `rimraf`, `fork-ts-checker-webpack-plugin`, `testcontainers`, etc.
- Do not run `npm audit fix` or `npm audit fix --force`.
- Do not change `@nestjs/platform-express`, `@modelcontextprotocol/sdk`, or `nest-commander` major lines.

## 4. Affected Paths

- `package.json` — add `overrides` for `fast-uri`, `js-yaml` parents.
- `package-lock.json` — regenerated by `npm install`.

## 5. Test Plan

- `npx jest packages/common/__tests__/site-from-domain.spec.ts apps/api/src/jobs/__tests__/jobs.service.spec.ts apps/api/src/jobs/__tests__/jobs.controller.spec.ts`
- `npx tsc --noEmit -p packages/common/tsconfig.json`
- `npx tsc --noEmit -p packages/models/tsconfig.json`
- `npx tsc --noEmit -p apps/api/tsconfig.json`
- `npm audit --audit-level=high` should show only the unavoidable `brace-expansion` high.
